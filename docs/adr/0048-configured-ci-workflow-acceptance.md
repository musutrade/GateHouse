## Decision

Run a declarative acceptance matrix inside the existing required Linux Test job.
Project metadata, capability contracts, producer/series identities and profile
select fixture work. The same signed collector protocol, retained-response
validation, verifier and released Rust evaluator handle every shape. No new
job, ecosystem dispatch or production measurement series is introduced.

A producer launch ledger and removal of its executable prove reuse without
fallback collection. Compare the complete direct Rust and verify project reports;
retain exact configuration, source/artifact bytes, retained response pins,
unified reports and negative results. The Python receipt validator checks
identity, completeness and integrity only; it cannot evaluate generic policy.
Upload the receipt and summary with checkout/run/attempt identity for 30 days.

The existing quality-coverage job remains the sole production coverage/risk/CRAP
owner. Its seal, independently transported manifest digest and consumer validation
remain intact. Generic Shadow keeps its advisory reference role. Required Quality
Aggregate still evaluates child outcomes only; native Linux/macOS/Windows tests
and native push assurance, pinned tools, source cache and disabled compiled caches
are unchanged. Synthetic fixtures are explicitly excluded from production sources.

## Consequences

Rust, Angular/reference and mixed fixture shapes exercise configured policy,
including optional unsupported Angular CRAP. An unregistered ecosystem with
bundle-size capability and arbitrary producer/series metadata proves generic
routing. Unknown metric semantics remain a released-core certification boundary;
changing capability identity in retained evidence is rejected. This matrix does
not claim new native Angular instrumentation or certification of custom metrics.
Existing native tests and reference/certification suites remain required.

Receipt elapsed time measures the acceptance test only. Completed hosted run/job
records must establish total runner work and critical path before accepting cost
claims. Retained historical cohorts inform the decision to keep ineffective
compiled-cache/build-once experiments reverted; they do not measure this change.
No reduction is claimed. See [validation and hosted handoff](../quality/gh-186/validation.md).

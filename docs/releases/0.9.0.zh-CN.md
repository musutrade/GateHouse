# Core 0.9.0 候选（未发布）

新增独立 gate-runtime/v3 只读镜像 readiness 协议和受保护的 installed-v2
宿主。Core 为每次调用生成新身份，绑定适配器、精确配置和镜像；仅 Docker
readiness_host 显式选择此路径。失败不会回退 CLI，Capabilities 不是 readiness。

依赖 gatehouse-runtime-protocol 0.2.0，必须先发布并验证协议 crate，再发布
Core。0.8.0 已发布且不包含 v3，禁止覆盖旧 tag 或将其声明为 v3 兼容。

取消边界测试使用仅测试编译存在的验证后观察点，替代固定 600ms 等待。
本地测试通过不代表 Windows 验收完成；Windows shard1 将保留十次精确测试
执行日志，任何一次失败均阻断，正常分片回归仍保留。既有 Quality Trends
冷启动及五次热运行仍是独立补充证据，历史失败不撤销。

当前只有假 Unix socket 验收。无真实 daemon、Podman、rootless、重启检测或
OS containment 证明；无 mutation、Remove、Absent 或 lease 自动迁移。
服务启动、停止和清理仍在 Core，#62 不能关闭。

docker-readiness 0.2.0 包和 importer 0.2.0 尚未完成交付，不声明下载制品兼容。
旧 docker-runtime 0.1.1 / importer 0.1.0 制品及其声明保持不可变。

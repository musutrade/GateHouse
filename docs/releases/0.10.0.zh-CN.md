# Core 0.10.0 候选：Docker 生命周期剥离

尚未发布。依赖协议 crate 0.3.0，发布前必须完成精确提交 CI、协议发布和下载制品验收。

Docker 的具体引擎操作由独立 docker-lifecycle 插件承担。Core 保留租约、恢复、取消协调与显式 operator 清理。托管 Docker 必须配置 lifecycle_host；readiness_host 不能授权变更，external_env 不能补全变更身份。Podman 仍走旧 Core 路径。

升级前停止旧 Core 进程，保持原项目与租约目录，用先前获准版本核实并处理旧 Docker 资源。新 Core 不采用旧 lease-v2，不按名称发现并删除容器；旧标记（包括悬空符号链接）阻止创建新槽。该检查不是跨版本共享锁。

本地真实 rootful Docker 已验证一次正常启动/健康/清理和一次健康失败保留/显式恢复。rootless、daemon 重启及其他真实故障组合尚未验证；不得扩大为完整引擎支持声明。生命周期产品、importer 和下载组合仍待发布与验收，#62 不能关闭。

拟定交付顺序：先完成 onboarding 对候选 0.10.0 的兼容性并发布新 pin（如 CI 要求），再协议 0.3.0 → Core 0.10.0 → docker-lifecycle 0.1.0 → importer 0.3.0。旧标签和制品保持不可变。

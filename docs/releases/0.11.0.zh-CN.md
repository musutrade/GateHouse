# Core 0.11.0 候选：Podman 只读捕获

当前未发布。新增显式 Linux `podman-capture`，要求规范绝对项目根路径和
`--trust-host`。固定读取项目 `.harness-gate/runtime/podman-capture-v1/host.json`，
按受保护安装描述符执行 native 适配器，使用本地 socket 的 info/image/info GET。
只返回规范证据，不自动落盘，不赋予 mutation、lease、恢复或调度权限。

协议依赖为精确 0.4.0；已有 Docker v1、runtime v2、readiness v3 保持独立。
Podman legacy service CLI 仍在 Core，不能关闭 #62 或声称生命周期已剥离。

本地测试覆盖真实子进程、假 Unix socket、显式信任与配置、规范 stdout、取消、
超时、断管和 fd 标志恢复。没有真实 Podman、rootless、重启、认证或 OS 隔离证明。
ENV131 环境缺少固定引擎与运行条件；真实验收须另行完成。

发布链为 protocol0.4 → Core0.11 → 只读 podman-lifecycle0.1；标准离线安装另需
importer0.4。所有现有标签/制品保持不可变。新产品包、下载验收和导入器尚未交付。

# Harness-Gate Core 0.4.8 与独立测量/插件包

本次交付 Core 0.4.8 和四个可独立安装的测量包。Core 提供 Linux x86-64、macOS Intel/Apple Silicon、Windows x86-64 二进制，并发布到 crates.io。四个包随同一个不可变 GitHub 标签 `v0.4.8` 交付，保留各自版本与测量序列身份；不会自动安装或替换已有项目的 collector 配置。

| 组件 | 版本 | 本次内容与运行要求 |
| --- | --- | --- |
| Core | 0.4.8 | core/plugin 拆分准备：每种 schema 角色只有一个可编辑源，generated 副本与 fixture 归属有记录且强制执行，决策夹具移入核心 crate；安装布局的 collector 协议 schema 查找修正；基准探针不再进入自身计时套件；包含 GH-269 适配器 nonce 修复。 |
| Rust measurer | 0.3.1 | 首次作为独立包发布。函数级 AST 复杂度分析器（identity `harness-gate-rust-measure/0.3.1`，rule `mccabe-rust-3`），供核心 CI 函数风险门禁消费；解包即用，不要求检出本仓库源码。 |
| Rust source risk | 0.1.0-rc.7 | 源码复杂度、原生 LLVM 覆盖率与 CRAP。需要 Rust 1.97.1、对应 LLVM 22.1.6 工具与 Python 3.14。 |
| TypeScript risk | 0.1.0-rc.4 | 基于原始 TypeScript AST 与 Istanbul 映射的函数复杂度、覆盖率、CRAP；不兼容协议版本现在显式失败并给出期望/实际值。需要 Node 24；TypeScript 6.0.2 由 shrinkwrap 锁定。 |
| HTTP JSON contract | 0.1.0-rc.5 | 独立 HTTP/JSON 契约与 Angular 写客户端检查。依赖锁定 TypeScript 6.0.2；本次在 Node 24 验证。 |

Core 质量阈值、签名校验、重放防护和非回退判定保持原有语义。Rust measurer 与 Rust source risk 是不同的分析器与测量序列，不能互相替代；升级须重新审核绑定与基线。

## 拆分准备范围

本版本不移动仓库、不改 CLI/crate/安装入口，也不改变任何测量语义。只做拆分前置：`schema/`、`tools/harness-gate/quality-core/schema/` 与 `tools/quality/schema/` 的同名 schema 现在每个角色只有一个可编辑源，其余标记为 generated 并由测试校验；核心不再通过 `include_str!` 引用插件 fixture；TypeScript-risk 独立链已在安装制品上完成 Core 决策验收。测量器打包（本版本新增）是下一步"核心 CI 消费固定制品"的前置。

## 安装 Core

从 `v0.4.8` 标签获取仓库根目录 `install.sh` 后执行：

```sh
bash install.sh --version v0.4.8
# 可选：同时安装原生 Rust/MIR RC7
bash install.sh --version v0.4.8 --with-rust
# 或从 crates.io 安装 Core
cargo install harness-gate --version 0.4.8 --locked
```

## 下载与验证独立测量/插件包

四个包的下载位置为本次 [GitHub Release](https://github.com/musutrade/Harness-Gate/releases/tag/v0.4.8)。npm 格式包通过 GitHub 分发，本次不向 npm registry 发布。

```sh
mkdir harness-gate-0.4.8
cd harness-gate-0.4.8
gh release download v0.4.8 --repo musutrade/Harness-Gate
sha256sum --check SHA256SUMS
```

安装前使用 cosign 对所选包进行签名校验，例如：

```sh
PACKAGE=harness-gate-rust-measure-0.3.1-linux-amd64.tar.gz
cosign verify-blob \
  --signature "$PACKAGE.sig" --certificate "$PACKAGE.crt" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity https://github.com/musutrade/Harness-Gate/.github/workflows/release.yml@refs/tags/v0.4.8 \
  "$PACKAGE"
gh attestation verify "$PACKAGE" --repo musutrade/Harness-Gate \
  --signer-workflow musutrade/Harness-Gate/.github/workflows/release.yml
```

对其他包替换 `PACKAGE` 并执行同样的校验。`release-inventory.json`、`SHA256SUMS`、包本体和各自 SBOM 均进入签名与证明集合。npm 安装仍需联网获取 shrinkwrap 固定的依赖；包不包含 Node、Python 或 Rust/LLVM 运行时。

## 独立安装

```sh
npm install --ignore-scripts --omit=dev --prefix "$HOME/.local/lib/harness-gate/typescript-rc4" \
  ./harness-gate-typescript-collector-0.1.0-rc.4.tgz
npm install --ignore-scripts --omit=dev --prefix "$HOME/.local/lib/harness-gate/http-contract-rc5" \
  ./harness-gate-http-json-contract-collector-0.1.0-rc.5.tgz
mkdir -p "$HOME/.local/lib/harness-gate"
tar -xzf harness-gate-rust-source-risk-0.1.0-rc.7-linux-amd64.tar.gz \
  -C "$HOME/.local/lib/harness-gate"
tar -xzf harness-gate-rust-measure-0.3.1-linux-amd64.tar.gz \
  -C "$HOME/.local/lib/harness-gate"
```

Node 入口在对应前缀的 `node_modules/.bin/`；Rust source 入口为解压目录下的 `plugin.py`，相邻 `inventory` 必须保留；Rust measurer 入口为解压目录下的 `harness-gate-rust-measure`，`plugin.json` 记录其 identity（`harness-gate-rust-measure/0.3.1`，rule `mccabe-rust-3`）。按各插件 README 配置 host 审核的源目录、捕获证据、collector executable pin、签名请求和完整测量序列。安装本身不创建签名密钥、不批准基线，也不代表项目质量通过。保留旧版本目录与绑定可供显式回滚。

## 验证边界

发布工作流先验证精确 main 提交的 CI，再构建四平台 Core，运行发布质量检查和插件测试。TypeScript 包同时对本次 Linux Core 执行集成测试；Node 包进行全新前缀安装与版本验证；Rust source 包运行 AST、协议、压缩证据及真实 rustc/LLVM 闭包回归；Rust measurer 包在解包后以 smoke 源校验 analyzer/version/rule 身份并生成 SBOM。全部包及 SBOM 通过同一受保护发布环境签名、证明并上传。公开下载后的验证结果记录在 `docs/release-status.md`。

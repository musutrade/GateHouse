# GateHouse Core 0.8.0（待发布）

新增 Linux `adapter runtime-probe-installed`，使用独立的
`gate-runtime-host/installed-v1` 宿主配置和 `gate-runtime-installation/v1`
安装描述符。描述符、配置、期望请求和可执行文件必须通过受保护路径、元数据、
摘要及身份一致性检查；旧 v2 命令不接受新格式，不自动降级。

此版本仍为只读宿主：仅允许 Inspect-only capabilities、Present 或 Unavailable，
不支持 Remove/Absent，不替换服务引擎、不迁移租约，也不完成 #62。
联合验收使用假 Unix socket；没有真实 Docker、rootless、重启检测、daemon
认证或 OS 隔离结论。描述符 provenance 是审计信息，不是发布者认证。

GateProbes 离线 importer 单独交付；docker-runtime-v0.1.1 保持不可变。
该旧包的 plugin-manager 元数据及 accept.py 仍仅声明 Core0.7.1；新版本
只验证直接导入与 installed-host 路径，不扩大旧包的兼容声明。

发布前需先交付 onboarding-presets1.0.3 并固定其摘要，以支持精确 Core0.8.0
版本门禁。源码候选验收与下载发行版验收必须分开记录。最终联合验收须使用
下载的 Core0.8.0、importer0.1.0、runtime0.1.1 和 onboarding1.0.3。

协议 crate 升为0.1.1，Core 精确依赖 =0.1.1；协议源码语义未改变，但新标签
改变 Cargo VCS 打包身份，不得复用0.1.0注册表摘要。沿用先协议发布与核验、
再 Core 打包预检和发行的流程。Core crate 上传仍在 GitHub 制品之后，不能
保证无部分交付窗口；失败时保留不可变标签并报告两个渠道状态，不盲目重试。

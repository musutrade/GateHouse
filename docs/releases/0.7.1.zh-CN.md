# GateHouse Core 0.7.1（待发布）

此补丁修复 0.7.0 的 crates.io 交付：runtime-protocol 路径依赖缺少版本约束，
且协议 crate 当时禁止发布。v0.7.0 的 GitHub 制品已经发布，注册表发布失败；
原标签、制品和失败记录保持不变。

Core 固定依赖 gatehouse-runtime-protocol =0.1.0，须先完成该协议 crate 的独立
发布及注册表核验。发行质量阶段新增 cargo publish --dry-run，在 GitHub 制品
发布之前验证注册表依赖解析和打包。它不保证后续上传凭据或网络一定可用。

onboarding-presets 需要新的 1.0.2 制品，保留既有版本并声明精确的 0.7.1
兼容性。先验收已发行 0.7.0 与源码候选 0.7.1；候选证据不能替代下载发行版
验收。最终 Core 标签和制品摘要以成功发布后的清单为准。

[0.7.0 的功能与信任边界](0.7.0.zh-CN.md)继续适用：Linux 只读 runtime host、
假 socket 验收、无真实 daemon 兼容结论，无 engine 切换、租约迁移或 mutation。
本补丁不完成 #62，也不涉及 PR #127。

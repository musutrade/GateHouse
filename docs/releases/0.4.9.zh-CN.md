# GateHouse Core 0.4.9

状态：准备发布，公开发行与验证回执待完成。0.4.9 是 GateHouse 的首个拆分后
Core 版本。命令、crate 名和 `.harness-gate/` 配置目录保持不变。

## 交付范围

- Core 提供 Linux x86-64、macOS Intel/Apple Silicon、Windows x86-64 二进制，
  Core SBOM、固定发行清单、checksum、Sigstore 签名与 GitHub provenance，并发布到 crates.io。
- TypeScript risk、HTTP/JSON contract、Rust source-risk、Rust measurer 由
  GateProbes 独立发布；Core 的发行清单不再携带这些插件包。
- Core 仅内置 `generic`。`rust-api`、`angular-only`、`angular-rust-postgres`
  通过审阅过的 GateProbes `presets/` 目录加载，详见[预设指南](../quality-presets.md)。
- 源码与未来 Core 签名身份迁移到 GateHouse；v0.4.8 及以前的安装与签名身份
  保留在 Harness-Gate，历史资产不重签、不覆盖。
- 精简 checkout 的完整回归与发布验证使用固定摘要的可选数据。CI 复用下载缓存、
  按数据分组隔离 cache key，并设置任务超时。

## 基线与兼容性

发布基于最新合入且通过 protected-main CI 的精确提交。
[已接受的 Phase 1 基线](../benchmarks/phase-1/README.md)仍是原始记录；
[旧 #346 候选审查](../quality/retained-baseline-review/README.md)因计时测试集变化
而拒绝采纳。没有重置历史 debt、lineage、阈值、required gates 或测量系列。
Engineering Policy 语义保持不变。

从 0.4.8 升级时，使用生态预设的初始化命令需要显式提供 `--presets-dir` 或
`HARNESS_GATE_PRESETS_DIR`。已有项目生成的 TOML 仍由项目维护；升级不会自动
安装插件、签署请求或采纳质量基线。保留旧二进制与配置供显式回滚。

## 发布完成后的安装

```bash
curl --fail --show-error --location --proto '=https' --tlsv1.2 \
  -o /tmp/harness-gate-install-0.4.9.sh \
  https://raw.githubusercontent.com/musutrade/GateHouse/v0.4.9/install.sh
bash /tmp/harness-gate-install-0.4.9.sh --version v0.4.9
# 或从 crates.io 安装 Core
cargo install harness-gate --version 0.4.9 --locked
```

可选 GateProbes 原生插件保持独立版本选择：

```bash
bash /tmp/harness-gate-install-0.4.9.sh --version v0.4.9 --with-rust \
  --rust-version 0.1.0-rc.8
```

匹配的 Rust/LLVM、Python 等外部采集依赖由用户提供；Core 单独安装不需要它们。
插件安装、度量认证与项目策略采纳是独立步骤。

```bash
harness-gate --version
harness-gate --project-root /path/to/project init --preset rust-api \
  --presets-dir /path/to/GateProbes/presets
harness-gate --project-root /path/to/project config check
harness-gate --project-root /path/to/project doctor
# 按生成的 QUALITY.md 准备可信 state、签名请求与密钥
harness-gate --project-root /path/to/project verify --profile ci --all
```

## 下载与签名验证

```bash
mkdir gatehouse-0.4.9
cd gatehouse-0.4.9
gh release download v0.4.9 --repo musutrade/GateHouse
sha256sum --check SHA256SUMS
cosign verify-blob \
  --signature harness-gate-linux-amd64.sig \
  --certificate harness-gate-linux-amd64.crt \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity https://github.com/musutrade/GateHouse/.github/workflows/release.yml@refs/tags/v0.4.9 \
  harness-gate-linux-amd64
gh attestation verify harness-gate-linux-amd64 --repo musutrade/GateHouse \
  --signer-workflow musutrade/GateHouse/.github/workflows/release.yml
```

发行清单中的其他签名/证明主体执行同样校验。安装器校验固定版本的清单与
二进制签名后替换私有安装目录中的文件。公开下载、安装与 crate 验证结果记录在
[交付状态](../release-status.md)，发布完成前不声称这些检查已通过。

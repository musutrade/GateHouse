# Harness-Gate Core 0.4.7 与独立插件候选包

本次交付 Core 0.4.7 和三个可独立安装、独立配置的插件 RC 包。Core 提供 Linux x86-64、macOS Intel/Apple Silicon、Windows x86-64 二进制，并发布到 crates.io。三个插件包随同一个不可变 GitHub 标签 `v0.4.7` 交付，保留各自版本与测量序列身份；不会自动安装或替换已有项目的 collector 配置。

| 组件 | 版本 | 本次内容与运行要求 |
| --- | --- | --- |
| Core | 0.4.7 | 新增 `quality.toml` 的 `[limits] max_artifact_bytes`；`verify`、`quality collect` 共用配置，未配置仍为 64 MiB；拒绝零、负数和溢出。 |
| Rust source risk | 0.1.0-rc.6 | 修正 Linux x86-64 安装包，包含 AST inventory、Python 入口及必需的 `ast/Cargo.lock`。支持源码复杂度、原生 LLVM 覆盖率、CRAP，Serde/JSON/format 宏、`tokio::select!`、闭包与 async 所有权，以及压缩证据。需要 Rust 1.97.1、对应 LLVM 22.1.6 工具与 Python 3.14。 |
| TypeScript risk | 0.1.0-rc.4 | 首次发布 npm 格式安装包；基于原始 TypeScript AST 和 Istanbul 映射计算函数复杂度、覆盖率、CRAP，支持文件级覆盖率和签名项目绑定。需要 Node 24；TypeScript 6.0.2 由 shrinkwrap 锁定。 |
| HTTP JSON contract | 0.1.0-rc.5 | 首次发布 npm 格式安装包；提供独立 HTTP/JSON 契约与 Angular 写客户端检查，支持业务闭合契约及 Angular functional interceptor 导入。依赖锁定 TypeScript 6.0.2；本次在 Node 24 验证。 |
| 原生 Rust/MIR 插件 | 0.1.0-rc.7 | 更新依赖归属缓存，减少大型项目重复扫描；新增签名 `source_prefix` 以支持 monorepo 路径绑定。四平台独立签名发布，Core 安装器默认升级为 RC7。 |

本次还整理了项目自有验证边界 ADR-0049，以及质量采集构建复用、最多两个默认并行测试（`--jobs` 可配置 1–8）的变更记录。核心质量阈值、签名校验、重放防护和非回退判定保持原有语义。三个新插件仍为 RC；源码风险与 MIR 是不同测量序列，升级须重新审核项目绑定与基线，不能直接混用。

## 修正范围

0.4.6 的公开解包验收发现 Rust source-risk RC5 漏带测量序列指纹需要的 `ast/Cargo.lock`。RC6 补齐该文件，发布前必须解包并运行全部 Rust runtime 测试；两个 Node 包也在全新安装目录运行完整测试。Core 0.4.7 是交付维护版本，Core 评价逻辑和度量公式保持不变。原生 RC7 继续使用其已验证的独立发行；两个 Node 插件保持版本和包内容不变。

旧标签、文件及失败记录保留。请使用本次 RC6 包并更新 host 审核的 collector 身份与 executable pin，不要使用 0.4.6 中不完整的 RC5 归档。此前 Core 0.4.6、原生 RC7 和两个 Node 插件的实际消费验证已经通过。

## 安装 Core

从 `v0.4.7` 标签获取仓库根目录 `install.sh` 后执行：

```sh
bash install.sh --version v0.4.7
# 可选：同时安装原生 Rust/MIR RC7
bash install.sh --version v0.4.7 --with-rust
# 或从 crates.io 安装 Core
cargo install harness-gate --version 0.4.7 --locked
```

## 下载与验证独立插件

三个插件的下载位置为本次 [GitHub Release](https://github.com/musutrade/Harness-Gate/releases/tag/v0.4.7)。npm 格式包通过 GitHub 分发，本次不向 npm registry 发布。

```sh
mkdir harness-gate-0.4.7
cd harness-gate-0.4.7
gh release download v0.4.7 --repo musutrade/Harness-Gate
sha256sum --check SHA256SUMS
```

安装前使用 cosign 对所选包进行签名校验，例如：

```sh
PACKAGE=harness-gate-typescript-collector-0.1.0-rc.4.tgz
cosign verify-blob \
  --signature "$PACKAGE.sig" --certificate "$PACKAGE.crt" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity https://github.com/musutrade/Harness-Gate/.github/workflows/release.yml@refs/tags/v0.4.7 \
  "$PACKAGE"
gh attestation verify "$PACKAGE" --repo musutrade/Harness-Gate \
  --signer-workflow musutrade/Harness-Gate/.github/workflows/release.yml
```

对另两个包替换 `PACKAGE` 并执行同样的校验。`release-inventory.json`、`SHA256SUMS`、包本体和各自 SBOM 均进入签名与证明集合。npm 安装仍需联网获取 shrinkwrap 固定的依赖；包不包含 Node、Python 或 Rust/LLVM 运行时。

## 独立安装

```sh
npm install --ignore-scripts --omit=dev --prefix "$HOME/.local/lib/harness-gate/typescript-rc4" \
  ./harness-gate-typescript-collector-0.1.0-rc.4.tgz
npm install --ignore-scripts --omit=dev --prefix "$HOME/.local/lib/harness-gate/http-contract-rc5" \
  ./harness-gate-http-json-contract-collector-0.1.0-rc.5.tgz
mkdir -p "$HOME/.local/lib/harness-gate"
tar -xzf harness-gate-rust-source-risk-0.1.0-rc.6-linux-amd64.tar.gz \
  -C "$HOME/.local/lib/harness-gate"
```

Node 入口在对应前缀的 `node_modules/.bin/`；Rust source 入口为解压目录下的 `plugin.py`，相邻 `inventory` 必须保留。按各插件 README 配置 host 审核的源目录、捕获证据、collector executable pin、签名请求和完整测量序列。安装本身不创建签名密钥、不批准基线，也不代表项目质量通过。保留旧版本目录与绑定可供显式回滚。

## 验证边界

发布工作流先验证精确 main 提交的 CI，再构建四平台 Core，运行发布质量检查和插件测试。TypeScript 包同时对本次 Linux Core 执行集成测试；Node 包进行全新前缀安装与版本验证；Rust source 包运行 AST、协议、压缩证据及真实 rustc/LLVM 闭包回归。全部包及 SBOM 通过同一受保护发布环境签名、证明并上传。公开下载后的验证结果记录在 `docs/release-status.md`。

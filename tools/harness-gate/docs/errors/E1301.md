## Why this fails

Git could not provide the requested changed-file scope. Repository selection, requested revisions and the staged snapshot are inputs to the scope decision.

## Diagnose and repair

Check the selected repository, Git availability and requested revision or staged snapshot. Retry with the intended scope after correcting the Git error.

Use the accompanying error and retained logs to identify the failed operation.
A corrected invocation is not itself a passing verification; inspect the new
result after rerunning the intended command.

## Example

If a requested base revision is missing in a shallow checkout, make that intended revision available before retrying. Do not substitute an unrelated revision or silently use an empty change set.

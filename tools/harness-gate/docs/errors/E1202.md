## Why this fails

Secret scanning encountered an execution failure. Read the actual error and any retained findings to distinguish inaccessible inputs from credential remediation work.

## Diagnose and repair

Inspect the scan error or finding, correct unreadable inputs, and remove or rotate exposed credentials as applicable. Do not bypass required scanning.

Use the accompanying error and retained logs to identify the failed operation.
A corrected invocation is not itself a passing verification; inspect the new
result after rerunning the intended command.

## Example

For an unreadable input, fix access and rerun the complete required scan. If evidence also identifies an exposed credential, remove it from tracked inputs and rotate it through the appropriate system. Do not suppress the scanner exit status.

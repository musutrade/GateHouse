## Why this fails

Verification execution encountered an error. The top-level code does not identify which command, dependency or evidence operation failed; the first underlying error does.

## Diagnose and repair

Inspect the first execution error and step logs. Correct the command, environment or prerequisite failure, then generate fresh verification evidence.

Use the accompanying error and retained logs to identify the failed operation.
A corrected invocation is not itself a passing verification; inspect the new
result after rerunning the intended command.

## Example

A missing command executable should be repaired in the execution environment, then the intended verification rerun. Do not add a shell fallback that converts the missing tool into exit status zero.

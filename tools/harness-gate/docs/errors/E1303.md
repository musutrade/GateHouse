## Why this fails

Changed files were left unmatched under the configured scope policy. Their required verification scope has not been established.

## Diagnose and repair

Review each unmatched path and assign it to the correct component with reviewed scope rules. Do not exclude changed files merely to pass verification.

Use the accompanying error and retained logs to identify the failed operation.
A corrected invocation is not itself a passing verification; inspect the new
result after rerunning the intended command.

## Example

A newly added directory may need a reviewed rule mapping it to the correct component. Include that rule and check representative paths. Do not exclude the directory or switch to a permissive policy simply to silence the failure.

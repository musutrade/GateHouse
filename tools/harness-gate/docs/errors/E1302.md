## Why this fails

The scope configuration could not be accepted. Invalid rules cannot reliably select the components that verification must cover.

## Diagnose and repair

Inspect the scope rule diagnostic and correct invalid patterns, components or configuration before rerunning scope.

Use the accompanying error and retained logs to identify the failed operation.
A corrected invocation is not itself a passing verification; inspect the new
result after rerunning the intended command.

## Example

When a rule references a component that is not declared, correct the component identifier or declare the intended component consistently. Do not remove the rule and assume the affected files no longer require checks.

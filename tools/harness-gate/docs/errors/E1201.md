## Why this fails

Secret scanning could not accept its configuration. An invalid scanner configuration cannot establish that the project is free of exposed credentials.

## Diagnose and repair

Correct the named secret-scan configuration error. Keep required scanning enabled and avoid printing secret values.

Use the accompanying error and retained logs to identify the failed operation.
A corrected invocation is not itself a passing verification; inspect the new
result after rerunning the intended command.

## Example

Correct a malformed rule or the named configuration path using the scanner contract. Keep the intended detection rule active, and never paste a real credential into a shared bug report as a sample.

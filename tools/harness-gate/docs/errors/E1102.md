## Why this fails

Architecture audit execution encountered an error. Configuration loading and a completed audit finding are distinct stages; the original error identifies what prevented execution.

## Diagnose and repair

Inspect the audit error and scan inputs. Correct the execution or access problem before rerunning the required audit.

Use the accompanying error and retained logs to identify the failed operation.
A corrected invocation is not itself a passing verification; inspect the new
result after rerunning the intended command.

## Example

When a scan input cannot be accessed, repair the intended path or permissions and rerun the audit. A partially scanned tree is not evidence that the remaining files satisfy the architecture rules.

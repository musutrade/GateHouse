## Why this fails

The parse-logs operation failed while reading or processing bounded UTF-8 lines, or while writing its output. Unrecognized or invalid JSON records can be skipped; when no trace ID is found the implementation can fall back to a raw tail. A different log format alone does not necessarily cause this error.

## Diagnose and repair

Inspect the input and output paths and the original I/O error. Check UTF-8 encoding and the 1 MiB per-line bound. Correct the producer or destination and retain the original log. This command does not offer a parser-selection repair.

## Example

If a producer writes a single line over 1 MiB, configure it to emit bounded records. If the error instead names an unwritable output directory, repair that destination; changing the input format would not resolve an output-write failure.

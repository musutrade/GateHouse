## Why this fails

The scope report could not be produced successfully. A previously existing report does not prove the current scope calculation was published.

## Diagnose and repair

Check the report destination and permissions. Correct the write failure and regenerate the scope report.

Use the accompanying error and retained logs to identify the failed operation.
A corrected invocation is not itself a passing verification; inspect the new
result after rerunning the intended command.

## Example

If the output directory is unwritable, correct the intended destination or permissions and regenerate the report for the same change set. Do not reuse an older report as if it described the current candidate.

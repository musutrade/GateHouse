## Why this fails

An artifact or log path is outside the invocation evidence boundary. Existing bytes outside that boundary cannot simply be accepted as current invocation evidence.

## Diagnose and repair

Inspect the affected artifact binding and invocation identity. Correct the producer or path and generate fresh evidence; do not edit manifests to make stale or missing evidence pass.

Inspect the original failure detail and the affected step or artifact. Preserve
the failed evidence and rerun the intended operation after correcting its cause;
this explanation does not change retry policy or the final decision.

## Example

Configure the producer to write its declared output within the invocation directory. Do not edit the manifest to bless an escaping path or copy an unrelated old result into place and claim it was generated by the current run.

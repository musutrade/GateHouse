# Independent TypeScript function risk collector

CodexSymphony requires CRAP <= 10. Its frontend reference pack cannot currently
measure CRAP. Add a separately versioned/installable measurement-only plugin,
with exact original-source complexity/coverage provenance and Core evaluation.
Existing Engineering Policy semantics, Rust thresholds, required checks, generic
contracts and legacy TypeScript measurement series remain unchanged.

This change introduces a new candidate measurement series; it does not retroactively
certify old records, migrate baselines or grant release authority. Real Angular
source-map acceptance, trusted host integration and independent publication remain
explicit prerequisites to full application adoption. No fallback weakens a required
gate while those prerequisites are absent.
